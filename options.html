Chat

These apply on arena.ai conversation pages.

New chat

These become buttons in the top-left panel. A click opens that mode and can fill the composer.

Article

The popup's "Explain article" button sends the largest <article> on the page to arena.ai using this template. Placeholders: {article}, {title}, {url}.

Video

The popup's "Explain video" button sends YouTube subtitles to arena.ai using this template. Placeholders: {subtitles}, {title}, {url}. Subtitles come with timestamps like [05:23].

Prompts

These appear as the Prompts panel on arena.ai pages. Clicking one inserts it into the composer.

Codebase

Snapshot rules for the Codebase panel. The folder itself is picked on the arena.ai page — these settings apply when you press Rebuild there.
