# Arena Utils

Расширение Chrome для [arena.ai](https://arena.ai).

Умеет экспортировать чаты в Markdown, вставлять заготовки промптов, собирать
снапшот кодовой базы по запросу, возвращать обычный скроллбар, отключать
автоскролл, сворачивать блоки кода, перемещаться по сообщениям и хранить
закладки.

## Языки

Расширение поставляется с английским (`en`) и русским (`ru`). Переводы лежат в
`_locales/<код>/messages.json`; в манифесте `"default_locale": "en"`.
Чтобы добавить новый язык, достаточно создать там новую папку — больше ничего
менять не нужно.

## Возможности

### Экспорт

Попап на иконке → **Экспорт чата**. Каждое сообщение сохраняется в Markdown-файл
внутри папки, названной по id чата из URL, с нумерацией в порядке появления на
странице (`1.md`, `2.md`, `3.md`, …).

Markdown берётся из React-пропсов, при неудаче — из DOM.

Файлы скачиваются через blob-URL, созданные в offscreen-документе; если это не
работает — есть откат на `data:`-URL.

### Новый чат

Свёрнутый чип слева сверху на странице переписки (`/c/...`). На страницах
нового чата (`/`, `/text`, `/text/direct`, …) панель развёрнута.

Шаблоны — в **Options → New chat**. Кнопка открывает URL нужного режима:

- Battle → `/`, `/text`, `/code`, `/image`, `/search`, `/video`
- Agent Mode → `/agent`
- Direct → `/{категория}/direct?model_a=...`
- Side by Side → `/{категория}/side-by-side?model_a=...&model_b=...`

Необязательный начальный промпт вставляется в поле ввода после загрузки.
Сообщение само не отправляется.

### Автоскролл

Чекбокс в попапе **Отключить автоскролл после ответов ИИ**. Страница перестаёт
прыгать вниз после ответа модели; ручной скролл не трогается, кнопки навигации
работают.

Реализовано через патч `scrollIntoView` / `scrollTo` / `scrollBy` в MAIN-мире
страницы (`pageBridge.js`).

### Промпты

Заготовки (название + текст) в **Options**. Они появляются как панель
**Prompts** на страницах arena.ai; клик вставляет текст в поле ввода
(`textarea[name="message"]`), не отправляя сообщение.

### Кодовая база

Chrome не может прочитать произвольный путь вида `C:\project`. Вместо этого
расширение запрашивает папку прямо со страницы.

1. На любой странице arena.ai откройте панель **Codebase** в левой колонке
   (под **New chat** и **Prompts**).
2. Нажмите **Выбрать…** и выберите папку — список фрагментов появится сразу.
3. **Пересобрать** — пересобрать ту же папку, **Сменить…** — выбрать другую.
4. Клик по фрагменту вставляет его в поле ввода. Каждый фрагмент получает
   заголовок `Фрагмент n/N` (локализуется) — чтобы модель понимала, какая это
   часть снапшота и сколько всего частей.

Список фрагментов и handle папки живут только в текущей вкладке — reload
страницы их очищает.

Правила снапшота (максимум символов на чанк, exclude-паттерны, учёт корневого
`.gitignore`) — в **Options → Codebase**. Панель собирает снапшот с этими
настройками.

Формат снапшота совпадает с Python-хелпером (`compare_exports.py`):

- дерево каталогов
- содержимое файлов
- нарезка по лимиту символов

**Full exclude** полностью убирает пути (`.git/`, `node_modules/`, …).  
**Content exclude** оставляет их в дереве, но не читает содержимое (`.env`,
lock-файлы, `*.json`, …).

### Панель сообщений

Свёрнутый чип в правом верхнем углу страницы чата. Клик раскрывает панель.

- Текущая позиция, например `3/12`
- Подсветка активного пункта списка
- **↑ / ↓** — предыдущее / следующее сообщение (те же клавиши, если фокус не
  в поле ввода)
- **⤓** — в самый низ треда
- Клик по строке скроллит к **началу** сообщения

### Закладки

Нажмите ☆ в панели **Messages**, чтобы добавить чат в закладки. Закладки видны
в попапе; клик открывает чат в новой вкладке.

### Статья / Видео (из попапа)

На любой HTTP-странице с крупным `<article>` в попапе появляется кнопка
**Объяснить статью**: расширение извлекает статью, оборачивает в шаблон из
**Options → Article** и открывает новый Direct-чат arena.ai с готовым промптом.

На странице YouTube с субтитрами появляется **Объяснить видео**: субтитры
достаются через несколько откатов (page response → refetch → InnerTube-клиенты
→ DOM-панель транскрипта), форматируются с таймкодами `[mm:ss]` и попадают в
новый чат.

### Блоки кода

По умолчанию блоки кода в **ответах модели** свёрнуты. Шапка с языком и Copy
остаются; **Показать · N** разворачивает блок. Чекбокс в попапе и в
**Options → Chat**.

В экспорт всегда попадает полный Markdown.

### Скроллбар

arena.ai прячет скроллбар у Radix viewport. Расширение снимает это правило —
возвращается системный скроллбар.

## Установка

1. Откройте `chrome://extensions`
2. Включите режим разработчика
3. **Load unpacked** → папка расширения
4. После обновления файлов перезагрузите вкладки arena.ai

## Использование

- Иконка на панели: автоскролл, сворачивание кода, экспорт, статья/видео,
  промпты, закладки, отладочное профилирование
- ПКМ по расширению → **Options** — шаблоны, промпты, шаблоны статьи/видео,
  правила кодовой базы
- На странице чата панели в левой колонке идут сверху вниз: **New chat**,
  **Prompts**, **Codebase**; **Messages** — справа сверху

## Разрешения

- `downloads` — экспорт Markdown-файлов
- `storage`, `unlimitedStorage` — настройки, промпты, закладки
- `offscreen` — создание Blob URL для скачивания файлов из service worker
- `scripting` — инъекция экстракторов статьи / видео по требованию
- `https://arena.ai/*` — скрипты на страницах чата

Доступ к папке для панели Codebase — через системный диалог выбора каталога
прямо со страницы arena.ai, а не через произвольный путь на диске.

## Как добавить язык

1. Скопируйте `_locales/en/` в `_locales/<код>/`.
2. Переведите все `message` (ключи не меняются).
3. В `languageCode` укажите новый код.
4. Перезагрузите расширение. Пользователи с подходящим языком браузера получат
   новый язык автоматически; остальные — откат на `en`.
