# Arena Utils

Расширение Chrome для Direct-чатов на [arena.ai](https://arena.ai).

Экспорт переписки, вставка заготовленных промптов, снимок кодовой базы, обычный скроллбар, отключение автоскролла, сворачивание блоков кода и навигация по сообщениям.

## Возможности

### Экспорт

Попап на иконке → **Export chat**.

Каждый ход сохраняется в Markdown-файл. Имя папки — id чата из URL:

- `1.md`, `3.md`, `5.md`, … — сообщения пользователя
- `2.md`, `4.md`, `6.md`, … — ответы модели

(Если тред начинается с сообщения пользователя.)

Markdown берётся из React-пропсов, при неудаче — из DOM.

### Новый чат

Свёрнутый чип слева сверху на странице переписки (`/c/...`). На страницах нового чата (`/`, `/text`, `/text/direct`, …) панель развёрнута.

Шаблоны — в **Options → New chat**. Кнопка открывает URL нужного режима:

- Battle → `/`, `/text`, `/code`, `/image`, `/search`, `/video`
- Agent Mode → `/agent`
- Direct → `/{category}/direct?model_a=...`
- Side by Side → `/{category}/side-by-side?model_a=...&model_b=...`

Необязательный начальный промпт вставляется в поле ввода после загрузки. Сообщение само не отправляется.

### Автоскролл

Чекбокс в попапе **Disable autoscroll after AI replies**.

Страница больше не прыгает вниз после ответа модели. Ручной скролл не трогается, кнопки навигации работают.

### Промпты

Заготовки (название + текст) в **Options**. Они видны в попапе; клик вставляет текст в поле ввода (`textarea[name="message"]`), не отправляя сообщение.

### Промпты из кодовой базы

Расширение не может прочитать путь вида `C:\project`.

1. Попап → **Select folder…** (или Options → Codebase)
2. Выберите папку и нажмите **Generate prompts**
3. Чанки `context-0001`, `context-0002`, … появятся в попапе и вставляются как обычные промпты

Если доступ к папке отозван, откройте **Options → Codebase** и нажмите **Restore access**.

Формат снимка как у Python-скрипта:

- дерево каталогов
- содержимое файлов
- нарезка по лимиту символов

**Full exclude** полностью убирает пути (`.git/`, `node_modules/`, …).  
**Content exclude** оставляет их в дереве, но не читает содержимое (`.env`, lock-файлы, `*.json`, …).  
Опционально: учесть корневой `.gitignore`.

### Панель сообщений

Свёрнутый чип в правом верхнем углу страницы чата. Клик раскрывает панель.

- Текущая позиция, например `3/12`
- Подсветка активного пункта списка
- **↑ / ↓** — предыдущее / следующее сообщение (те же клавиши, если фокус не в поле ввода)
- **⤓** — в самый низ треда
- Клик по строке скроллит к **началу** сообщения

### Блоки кода

По умолчанию блоки кода в **ответах модели** свёрнуты. Шапка с языком и Copy остаются; **Show · N** разворачивает блок.

Чекбокс **Collapse code blocks in AI replies** в попапе и в Options.

В экспорт попадает полный Markdown.

### Скроллбар

arena.ai прячет скроллбар у Radix viewport. Расширение снимает это правило — возвращается системный скроллбар.

## Установка

1. Откройте `chrome://extensions`
2. Включите режим разработчика
3. **Load unpacked** → папка расширения
4. После обновления файлов перезагрузите вкладки arena.ai

Chrome может отзывать доступ к папке кодовой базы при перезапуске. Откройте **Options → Codebase** и нажмите **Restore access** рядом с именем папки. Кнопка появляется, когда handle сохранён, но разрешение браузера сброшено.

## Использование

- Иконка на панели: автоскролл, сворачивание кода, экспорт, промпты, чанки кодовой базы
- ПКМ по расширению → **Options** — промпты, флаги чата, настройки снимка
- На странице чата — чип **Messages** справа сверху

## Разрешения

- `downloads` — экспорт Markdown-файлов
- `storage`, `unlimitedStorage` — настройки, промпты, снимки
- `offscreen` — создание Blob URL для скачивания файлов из service worker
- `https://arena.ai/*` — скрипты на страницах чата

Доступ к папке — через системный диалог выбора каталога, не через произвольный путь на диске.
